# MOEX Historical Quotes Importer for Skillful Pro

Скрипт для получения исторических дневных котировок инструментов, торгующихся на Московской бирже (ММВБ).

## Описание проекта

Проект позволяет загружать, обновлять и в случае необходимости корректировать исторические данные стоимости акций, индексов, валютных пар и др. инструментов с биржи MOEX. 
Данные сохраняются в формате `.csv` в локальную директорию (по умолчанию Quotes, при первом запуске будет создана автоматически).

Для работы используется:
- **API MOEX**: [Документация ISS](https://iss.moex.com/iss/reference/)
- **Проект moex-importer**: [GitHub репозиторий](https://github.com/cdracer/moex-importer)

## Требования

Операционная система Windows 10 и старше.
Перед запуском необходимо установить **Python** (версия 3.x).
- Для Windows: скачайте и установите [Python](https://www.python.org/downloads/).

> **Важно:** Пользователь должен обладать правами на запись в папке, откуда запускается проект.

## Установка и запуск

1. Скачайте или клонируйте проект в удобную директорию на вашем компьютере.
2. Откройте терминал в папке проекта:
   - Вариант А: Нажмите правой кнопкой мыши в пустом месте папки → «Открыть в терминале».
   - Вариант Б: Откройте терминал отдельно (Win + X → Терминал) и перейдите в папку командой `cd`, например:  

     cd D:\Skillful\MOEX
     
## Использование

### Загрузка данных для конкретного инструмента

Чтобы загрузить исторические котировки для выбранного инструмента, передайте его тикер в качестве аргумента:

py _m.py SBER

Загрузит данные акций ПАО «Сбербанк».

py _m.py IMOEX

Загрузит данные индекса IMOEX.

py _m.py CNYRUB_TOM

Загрузит данные валютной пары Юань/Рубль.

Данные будут сохранены в папке Quotes, в корне проекта, в виде файла TICKER.csv (например, SBER.csv).

Обновление полученных данных. Запустите скрипт без параметров:

py _m.py

Скрипт просканирует все .csv файлы в директории Quotes, включая вложенные папки, и актуализирует данные.

Вы можете вручную организовать структуру папок в  Quotes по категориям (акции, индексы, валюты и т.д.). Скрипт корректно обработает все файлы.

Пример структуры:

\Quotes

    \Stocks
   
       ROSN.csv
       
       SBER.csv 
        
    \Indexes
   
       RTSI.csv
       
       MOEX.csv
       
    \Currencies
   
       CNYRUB_TOM.csv
       
Запуск команды py _m.py обновит все перечисленные файлы.

Дополнительные совет.

Для удобства можно создать ярлык на рабочем столе:

Нажмите правой кнопкой мыши на рабочем столе → «Создать» → «Ярлык».
В поле «Укажите расположение объекта» введите путь к скрипту, например:

D:\Skillful\MOEX\_m.py

Присвойте ярлыку удобное имя.

Теперь вы сможете обновлять все котировки двойным кликом на ярлыке.

## Корректировка котировок

В исторических данных инструментов попадаются баги с количеством знаков после запятой. Такие данные не поддерживаются
программным комплексом Skillful Pro (при открытии файла ошибка: "error file reading...").

Пример данные котировок акций ПАО "ВТБ", тикер VTBR:

Date,Open,High,Low,Close

2013-03-25,258.95,259.99999999999994,251.04999999999998,251.45000000000002

2013-03-26,252.05,253.50000000000006,241.70000000000002,245

С целью нормализации данных, используйте скрипт check_dec.py (запуск из папки проекта, файл с исправляемыми котировками должен находится в папке Quotes)

py check_dec.py VTBR 2

Где, VTBR тикер, 2 требуемое количество знаков после запятой. 

После выполнения скрипта, вышеприведённые данные будут иметь вид:

Date,Open,High,Low,Close

2013-03-25,258.95,259.99,251.04,251.45

2013-03-26,252.05,253.5,241.7,245

## Изменение название папки Quotes

При необходимости указать другое название, отредактируйте в любом текстовом редакторе файл quotes_folder.py d в 2-й строке:

FOLDER_NAME = "Quotes"

## Обновление данных полученных из другого источника

Данные полученные из другого источника будут корректно обновляется при соответствии полученных данных, вышеуказанному формату, название файла переименовано в имя_тикер.csv, например RU000A0ZYF20.csv (ПАО "ДОМ.РФ", облигация биржевая (RU000A0ZYF20)).

и если у вас уже существует папка Quotes, переименуйте её.
